Cannon é um jogo desenvolvido usando o motor gráfico pyxel para python

No jogo, você controla um canhão de artilharia que tem o dever
de impedir que inimigos se aproximem do fim da tela

O jogo possui três níveis enumerados: um tutorial com alvos
inofensivos, um nível com tanques inimigos e um nível com
tanques e um avião que traz soldados para o campo de batalha,
respectivamente

Mire o canhão usando o mouse e dispare com o botão esquerdo
Ajustes na distância são feitos selecionando a quantidade de
cargas explosivas para o disparo e a elevação do canhão.

Mantenha em mente que a elevação e quantidade de cargas também
influenciam o tempo de viagem do projétil
